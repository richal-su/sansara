## Проблема и решение

### Проблема

Опишите проблему, которую решает продукт: для кого она актуальна, в каких ситуациях возникает и почему существующие способы её решения недостаточны.

### Целевая аудитория

Укажите целевой сегмент пользователей, их потребности, контекст использования продукта и ключевые ограничения.

### Продуктовое решение

Кратко опишите продукт, его ценностное предложение и предполагаемый эффект для пользователя или заказчика.

## Правило документирования

Визуальные материалы в Unidraw дополняют документацию, но не заменяют её.

Для каждого артефакта, размещённого в Unidraw, должен существовать соответствующий Markdown-файл в каталоге `docs/`. В нём необходимо указать:

1. ссылку на доску Unidraw;
2. назначение артефакта;
3. основные элементы и использованные данные;
4. ключевые наблюдения, результаты или расчёты;
5. принятые решения;
6. обоснование решений и ограничения;
7. связь артефакта с последующими действиями команды.

Ссылка на доску без содержательного текстового комментария не считается завершённым результатом работы.
