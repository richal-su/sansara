## Цель и исходные данные

Панель предназначена владельцу продукта и оператору matching: она связывает воронку заявок, качество подбора и экономику сделок. Источники — пояснение команды к доске, [бизнес-модель](../../data/raw/business_model.txt), [unit-экономика](../03_product_strategy/unit_economics.md) и [ML-метрики](ml_metrics.md). Представленные ниже значения — иллюстрация интерфейса, не результаты пилота.

## Структура панели

North Star — GMV успешно завершённых сделок. Панель показывает воронку «заявки → совпадения → офферы → сделки», активные компании и товары, качество AI (Acceptance Rate и Precision по мере накопления разметки), экономику и очередь ручной проверки. Проценты конверсии описывают переходы и не являются отдельными событиями.

| Показатель | Пример |
|---|---:|
| Активные компании | 315 |
| Активные товары | 28 400 |
| Закупочные заявки | 1 720 |
| Найденные matches | 740 |
| Match Rate | 43% |
| Match → Deal | 19% |
| Сделки | 141 |
| GMV | 42,8 млн ₽ |
| Выручка | 1,02 млн ₽ |
| Take Rate | 2,4% |
| Recovered Capital | 39,5 млн ₽ |
| Buyer Savings | 7,8 млн ₽ |
| Repeat Rate | 41% |

Арифметика примера: 740 / 1 720 ≈ 43,0%; 141 / 740 ≈ 19,1%; 1,02 / 42,8 ≈ 2,38%. Округлённые значения согласуются, но не подтверждают реальную работу или пилот.

## Определения показателей

| Метрика | Смысл |
|---|---|
| GMV | Денежный объём успешно завершённых сделок |
| Match Rate | Доля заявок, для которых найден подходящий остаток |
| Match → Deal | Доля совпадений, дошедших до сделки |
| Time to Match | Время от заявки до подходящего предложения |
| Recovered Capital | Средства, возвращённые продавцами из остатков |
| Buyer Savings | Экономия покупателя с учётом условий сделки |
| Take Rate | Отношение комиссионной выручки к GMV |
| Repeat Rate | Повторные сделки компаний |
| Sell-through Rate | Доля проданных остатков |
| Acceptance Rate | Доля принятых предложений среди оценённых |

Комиссионную выручку и подписки необходимо учитывать раздельно. Пример среднего take rate не означает единую ставку для каждой компании: в гипотезе тарифов комиссии Start / Pro / Enterprise составляют 3% / 1,5% / 0,5%.

## Наблюдения и решения

В примере высокая доля найденных совпадений относительно конверсии в сделку указывает на возможную проблему закрытия сделки, которую предстоит проверить на пилоте. Оператору нужны причины отказов и очередь проверки, а владельцу продукта — связь качества подбора с GMV и экономией. Экономию и возвращённый капитал следует рассчитывать по фактическим условиям завершённых сделок.

Для сопоставимых измерений необходимо заранее определить период и когорту, единицу совпадения и учёт нескольких офферов к одной заявке. Инструмент BI в исходных материалах не выбран; пороги и фактические значения предстоит устанавливать по данным пилота.
