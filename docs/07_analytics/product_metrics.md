## Содержание

### North Star Metric

**GMV успешно завершённых сделок.**

### Основные метрики

| Метрика | Что показывает |
|---|---|
| GMV | Объём завершённых сделок |
| Match Rate | Доля заявок, где найден подходящий остаток |
| Match → Deal Conversion | Совпадения, дошедшие до сделки |
| Time to Match | Время от заявки до подходящего предложения |
| Recovered Capital | Деньги, возвращённые продавцами из неликвидов |
| Buyer Savings | Экономия покупателей |
| Take Rate | Доля выручки Sansara от GMV |
| Repeat Rate | Повторные сделки компаний |
| Sell-through Rate | Доля проданных неликвидов |

### AI-метрики

| Метрика | Смысл |
|---|---|
| Precision | Доля верных matches среди найденных |
| Recall | Доля найденных совпадений от всех существующих |
| Acceptance Rate | Доля подтверждённых пользователем AI-рекомендаций |

Для MVP приоритет: **Acceptance Rate**.

### MVP-набор

time-to-match, precision, conversion offer→deal, GMV, take rate, средняя экономия.

## Ключевые наблюдения

- Регистрации не являются главной метрикой — важны реальные сделки через платформу.

## Принятые решения

- Отслеживать ценность для обеих сторон (Recovered Capital и Buyer Savings), не только выручку платформы.

## Обоснование

Метрики связаны с win-win-win моделью monetization.
