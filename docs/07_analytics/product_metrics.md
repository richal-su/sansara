# Продуктовые метрики Sansara

## Ссылка на визуальный материал

[Открыть доску метрик и аналитической панели](https://unidraw.io/app/board/897320906af94565fc8f?allow_guest=true)

## Цель и исходные данные

Метрики показывают, помогает ли Sansara находить подходящие остатки для закупочных заявок и доводить предложения до взаимовыгодных сделок. Основа — бизнес-модель и пояснение команды к доске аналитики. Показатели описывают план измерения; фактические результаты пилота не представлены.

## Содержание

**North Star — GMV завершённых сделок:** сумма стоимости успешно завершённых сделок через Sansara за выбранный период. Показатель отражает оборот, но сам по себе не измеряет выручку, прибыль, экономию покупателя или качество подбора.

| Метрика | Определение | Для чего используется |
|---|---|---|
| Match Rate | Заявки, для которых найден подходящий остаток / все заявки | Оценить покрытие спроса доступными остатками |
| Match → Deal | Совпадения, дошедшие до сделки / найденные совпадения | Оценить переход от подбора к сделке |
| Time to Match | Время от заявки до подходящего предложения | Оценить скорость поиска |
| Acceptance Rate | Принятые предложения / предложения, по которым получено решение | Оценить полезность выдачи с учётом обратной связи |
| Recovered Capital | Средства, возвращённые продавцами из продажи остатков | Оценить ценность для продавца |
| Buyer Savings | Экономия покупателя с учётом фактических условий сделки | Оценить ценность для покупателя |
| Take Rate | Комиссионная выручка / GMV | Оценить долю оборота, полученную как комиссию |
| Repeat Rate | Доля компаний с повторными сделками | Оценить повторное использование |
| Sell-through Rate | Доля проданных остатков | Оценить реализацию размещённых остатков |

Комиссионная выручка и выручка от подписок учитываются раздельно. Для оценки AI дополнительно используются Precision, Recall и метрики ранжирования на размеченных примерах; их роль описана в [метриках качества ML](ml_metrics.md). Acceptance Rate зависит от решений участников и не заменяет техническую оценку совместимости.

Для оценки экономики на одной и той же базе компаний и за один горизонт дополнительно применяются:

| Метрика | Способ расчёта и ограничение |
|---|---|
| Средний чек сделки | GMV завершённых сделок / число завершённых сделок за период |
| CAC | Расходы на привлечение новых компаний / число привлечённых компаний; состав расходов и событие привлечения должны быть определены |
| Маржинальный доход сделки | Выручка платформы от сделки минус относящиеся к ней переменные расходы; показатель не равен чистой прибыли |
| LTV | Ожидаемый вклад одной компании за установленный горизонт; указываются число сделок, состав затрат и горизонт |
| LTV / CAC | LTV / CAC, рассчитанные для одинаковой единицы клиента и согласованного периода |

Событие активности, период измерения и единица учёта должны быть названы для каждой метрики. Для удержания сравнивают вернувшиеся компании с одной и той же исходной когортой; новые компании в неё не добавляют. Выручка платформы не равна GMV. Эти определения согласуются с глоссарием лекции 5 и не являются измеренными результатами Sansara.

## Ключевые наблюдения и решения

Воронка «заявки → совпадения → офферы → сделки» позволяет обнаружить, на каком этапе возникают потери. GMV выбран основной метрикой, поскольку продукт создаёт ценность через завершённые сделки; его следует рассматривать вместе с качеством matching, скоростью поиска и выгодой обеих сторон. Для оператора важны причины отказов и очередь ручной проверки. [Панель KPI](kpi_dashboard.md) содержит иллюстративный пример, а не результаты пилота.

## Ограничения и дальнейшие действия

Для сопоставимых расчётов до внедрения аналитики нужно определить период и когорту, единицу совпадения, правила учёта нескольких офферов по одной заявке, повторных сделок и проданных остатков. Экономию и возвращённый капитал рассчитывают по фактическим условиям сделок. Без размеченных примеров и данных пилота невозможно сделать вывод о качестве модели, конверсии или достижении целевых показателей.
