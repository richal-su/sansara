## Содержание

### P0 — обязательно

| ID | Элемент | Описание |
|---|---|---|
| P0-1 | Онбординг и подключение | Роль, Excel или 1С, маппинг полей, read-only |
| P0-2 | Дашборд продавца | Остатки, потенциальные офферы, сделки, выплаты |
| P0-3 | Дашборд покупателя | Заявки, предложения, экономия, сделки |
| P0-4 | Лента AI-офферов | Карточка с экономией; Принять / Изменить / Отклонить |
| P0-5 | Детали матча | Обоснование совпадения, характеристики, логистика, комиссия |
| P0-6 | Сделка | Чат, документы, статусы, оплата, доставка |
| P0-7 | Настройки правил | Мин. цена, скидки, регионы, авто-подтверждение, уведомления |
| P0-8 | Админка оператора | Очередь matching, ручная проверка, споры, метрики |
| P0-9 | Ingestion Excel/CSV | Загрузка, предпросмотр, импорт в каталог |
| P0-10 | Закупочные заявки | Загрузка потребности покупателя |
| P0-11 | Matching + Match Score | Жёсткие фильтры, semantic layer, score |
| P0-12 | Уведомления | Email или Telegram |

### Функции по ролям (сводка)

**Продавец:** интеграция, чтение остатков, нормализация, излишки, правила, лента офферов, документы, логистика вручную, выплаты, аналитика возврата капитала.

**Покупатель:** интеграция заявок, нормализация потребности, AI-подбор, карточка предложения, резерв/оплата, документы, аналитика экономии.

**Общие:** верификация компаний, статусы сделки, споры, рейтинг/история (сложный рейтинг — не MVP).

### P1 — желательно

- Аналитика (сэкономлено, излишки, оборачиваемость).
- История сделок, рейтинг компаний.
- Интеграция с ЭДО.

### P2 — позже

- Мобильное приложение, автоплатежи, API для ERP, собственная логистика.

### Matching pipeline (ядро)

Ingestion → нормализация → мастер-каталог → жёсткие фильтры → мягкий скоринг → совместимость объёмов → генерация оффера → human-in-the-loop → обратная связь для модели.

## Ключевые наблюдения

- Без качественного matching продукт превращается в обычную площадку.

## Принятые решения
